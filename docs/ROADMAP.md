# DZ Signage — Roadmap

Phases are sequential guidance for delivery. Do not implement future phases unless requested.

## Phase 0 — Project Foundation

Repo scaffold, Docker Postgres/Redis, Fortify auth shell, Inertia surfaces (`/`, `/app`, `/admin`, `/player`), Pest + Playwright smoke, authoritative `/docs` + Figma reference.

## Phase 1 — Authentication, Workspaces, Roles & Application Shells

Workspaces, membership, roles/policies, customer/admin shells aligned to Figma.

## Phase 2 — Media Library

Upload/manage reusable Media (images, videos, text, logos, documents, links).

## Phase 3 — Templates + Shared Rendering Schema

Platform + custom templates; introduce shared JSON rendering schema.

## Phase 4 — Screen Designs + Editor

Finished designs from templates; draft/publish versioning concepts.

## Phase 5 — Player + Pairing + First Real Publishing

Device pairing, player auth, first end-to-end publish to a screen.

## Phase 6 — Multi-Screen + Heartbeats + Screen States

Multiple screens; heartbeats; operational / pairing / network state axes.

## Phase 7 — Playlists

Ordered Screen Designs; durations/transitions/active flags.

## Phase 8 — Schedules

Named schedules selecting playlists; timing rules.

## Phase 9 — Publishing / Deployments

Assign Schedule / Playlist / Screen Design to screens; deployment records.

## Phase 10 — Offline Player Reliability

Cached manifests/assets; offline playback; local schedule execution.

## Phase 11 — Widgets

Planned widgets: Clock · Weather · News · Countdown · Calendar · Alerts · Configurable Cards · Live Stream / Embed.

## Phase 12 — Super Admin Expansion

Platform ops: workspaces, users, screens, templates, health, support, audit.

## Phase 13 — Billing / Subscriptions

Plans, entitlements, payment provider integration.

## Phase 14 — AI Content Generation

Planned: AI Images · AI Video · AI Text.

## Phase 15 — Analytics + Production Hardening

Usage analytics, observability, hardening for production scale.
